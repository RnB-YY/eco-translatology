# 生态翻译学

十八页中文 HTML 演示，包含韩汉翻译示例。

打开 `index.html`，使用方向键切换页面，或通过底部目录跳页。

发布：GitHub Pages，`main` 分支根目录。图片与字体随仓库保存。

## 内容说明

理论文献列于第18页。韩汉例句及译法比较为设定情境的说明示例。
胡庚申讲座照片由演示作者提供，展示版本经过 AI 清晰化处理。

## 个人知识星系

`universe/` 收录课程发表、研究资料与作品集入口。

四颗星球分别使用荒漠峡谷（自述）、迷雾雨林（学术发表）、晨雾湿地（视觉作品）与蓝色冰川（研究资料）。

## 史前景观结构

`prehistoric-landscape/` 为十六页韩语 HTML 演示，沿用地形封面与课程发表版式。支持方向键、触屏翻页、全屏与手机阅读视图。

`prehistoric-landscape/script.html` 为单独的韩语发表稿，可逐页跳转和调节字号。讲稿没有嵌入演示页。

`prehistoric-landscape/credits.html` 收录资料、图片及字体出处。
